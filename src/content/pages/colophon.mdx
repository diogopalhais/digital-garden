A peek behind the curtain at how this site was built and what inspired it.

## Built With

This digital garden is built with [Astro](https://astro.build), a modern static site generator that ships zero JavaScript by default. Content is written in MDX, allowing me to mix Markdown with interactive React components.

Styling is handled by [Tailwind CSS](https://tailwindcss.com) for rapid, consistent styling, with the Typography plugin for beautiful prose.

Animations are powered by [Motion](https://motion.dev), a lightweight animation library that respects user preferences for reduced motion.

## Stack

- **Astro** — Framework
- **React** — Interactive components
- **MDX** — Content
- **Tailwind CSS** — Styling
- **Motion** — Animations
- **TypeScript** — Type safety

## Typography

- **Inter** — UI and body text
- **JetBrains Mono** — Code and monospace

## Hosting

Hosted on [GitHub Pages](https://pages.github.com) with automatic deployments via GitHub Actions. The source code is available on GitHub.

## Inspiration

This site draws inspiration from modern developer portfolios and personal sites I admire. The bento grid layout creates an engaging, visual way to present information.
