A peek behind the curtain at how this site was built.

## Stack

- **Astro** — Static site framework
- **React 19** — Interactive components
- **Tailwind CSS v4** — Styling
- **Motion** — Animations
- **MDX** — Content
- **TypeScript** — Type safety
- **Cloudflare Workers** — Serverless APIs (Spotify, Trakt)

## Typography

- **Inter** — UI and body text
- **JetBrains Mono** — Code

## Colors

| Role | Value |
|------|-------|
| Background | `#000000` |
| Card | `#0a0a0a` |
| Accent | `oklch(0.67 0.185 55)` |
| Text | `#F8EDD9` |

## Hosting

Static site on [GitHub Pages](https://pages.github.com). Serverless functions on [Cloudflare Workers](https://workers.cloudflare.com).
